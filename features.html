[ 03 ] PRINTING TECHNIQUES

How the pattern gets onto the page.

Four core printing disciplines from the security-press world — each one chosen for a specific job in the document's defence.

P·01

Guilloché security designs

Definition
Intricate, mathematically generated geometric patterns used in security printing to enhance document security and deter counterfeiting.
Application
Used on banknotes, passports, certificates and other secure documents as backgrounds, borders and integrated security elements — complex, interlocking line work that is prohibitively difficult to reproduce.
Authentication
Verified by inspection, or with specialised authentication tools.
P·02

Watermarking

Definition
Visible or invisible marks incorporated into documents to support authentication and security.
Application
Company logos, seals or authentication data — incorporated as true-tone or multi-tone watermarks in the sheet itself, or as digital watermarks — to distinguish genuine documents and make unauthorised reproduction far harder.
Definition
—
P·03

Microprinting

Definition
Extremely small text or patterns, difficult to reproduce accurately — unreadable to the naked eye, verified under magnification.
Application
Adds fine security detail that photocopiers and desktop printers simply cannot resolve.
Used for
Security documents, certificates, tickets, visas, passports, ID and driver's licence cards.
P·04

Split-duct (rainbow) printing

Definition
Also known as rainbow printing — a single-pass process that combines multiple inks into smooth, continuous colour transitions.
Application
Creates distinctive colour patterns that are extremely difficult to reproduce accurately — an instant visual tell on any forgery.
Used for
Security documents, certificates, tickets, visas, passports, ID and driver's licence cards.

[ 05 ] HOLOGRAMS & FOILING

The features people recognise on sight.

Three-dimensional images and metallic foils — the most publicly legible layer of document security, and among the hardest to replicate.

H·01

Security holograms

Definition
Three-dimensional images created with holographic technology, featuring intricate patterns and optical effects — movement, depth and colour-shifting that are extremely difficult to reproduce accurately.
Application
Banknotes, identification cards, visas, passports and product packaging.
H·02

Foiling

Definition
Metallic or holographic foil applied to a document to create distinctive visual and security features — seals, logos, serial numbers and other verification marks.
Types
Hot-stamp foiling · cold foil transfer · holographic foiling.

BENEFITS

  • Visual authentication — instantly recognisable, extremely hard to replicate.
  • Anti-counterfeiting — the complexity and uniqueness of holograms and foils make documents highly resistant to reproduction.

USE CASES

  • Government documents — passports, visas and driver's licences, to prevent tampering.
  • Product packaging — brands authenticating goods against counterfeits.

[ 06 ] NUMBERING & CODES

Every document, one of one.

Unique identifiers and machine-readable information — connecting the physical document to its digital record.

N·01

Barcodes & QR codes

Definition
Printed or embedded optical codes storing unique or secure information — enabling automated verification, tracking and authentication.
Types
1D linear barcodes (UPC, EAN, Code 128) · 2D matrix codes (QR, Data Matrix) · invisible UV barcodes, hidden in normal light and visible under UV.
N·02

Security numbering

Definition
Unique, traceable, tamper-evident numbers assigned to each document during production — sequential, randomised or encrypted, and linked to a database for verification.
Printing techniques
Laser numbering (precise, durable, tamper-evident) · inkjet & thermal transfer (high-speed production) · dot-matrix (legacy security systems).
  • Authentication — unique identifiers confirm document authenticity.
  • Traceability — documents tracked through issuance, distribution and use.
  • Tamper detection — control numbers reveal alterations.
  • Data security — encrypted or digitally signed information.
